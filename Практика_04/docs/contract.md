# Контракт CountMap

## Общие правила

- Тип ключа задаётся параметром `T` и проверяется компилятором.
- `null` не является допустимым ключом или участником операции.
- Неизвестный ключ имеет количество `0`.
- Один экземпляр не предназначен для одновременного изменения из нескольких потоков.
- Сложение количеств использует `Math.addExact`; переполнение отклоняется `ArithmeticException`.

## Методы

| Метод | Предусловие | Результат | Возможный отказ |
|---|---|---|---|
| `add(T)` | ключ не `null` | количество ключа увеличено на один | `NullPointerException`, `ArithmeticException` |
| `getCount(T)` | ключ не `null` | текущее количество или `0` | `NullPointerException` |
| `remove(T)` | ключ не `null` | ключ удалён, возвращено прежнее количество или `0` | `NullPointerException` |
| `size()` | нет | число различных ключей | нет |
| `addAll(CountMap<? extends T>)` | источник не `null` | количества прибавлены, источник не изменён | `NullPointerException`, `ArithmeticException` |
| `toMap()` | нет | отдельный неизменяемый снимок | нет |
| `copyTo(Map<? super T, Integer>)` | приёмник не `null` и допускает запись | количества записаны; совпадающие значения заменены | `NullPointerException` или отказ конкретной карты-приёмника |

`remove` удаляет ключ целиком и возвращает количество до удаления. Он не уменьшает счётчик на единицу.

## Защита состояния

Внутренняя изменяемая `HashMap` не возвращается вызывающему коду. `Map.copyOf` создаёт отдельный снимок: вызов `put` запрещён, а последующий `add` не меняет уже полученный результат.
