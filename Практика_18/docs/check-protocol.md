## Фактические результаты

### Целевой профиль

```shell
./gradlew clean testIntegrationAndUi
```

Результат: 17 запусков, 0 отказов. В профиль вошли 10 сценариев временной SQLite, 5 проверок classpath-ресурсов и 2 JavaFX-сценария. Первый прогон выявил отсутствие CSS `id` у элементов, хотя `fx:id` для внедрения контроллера был задан. После добавления устойчивых `id` профиль прошёл полностью.

В отдельной временной копии путь `DesktopApp.FXML_RESOURCE` заменён на отсутствующий. Тот же профиль завершился кодом 1: 17 запусков, 5 ожидаемых отказов в ресурсных и JavaFX-проверках. Рабочая копия не изменялась и после эксперимента сохранила зелёный результат.

### Полная регрессия

```shell
./gradlew clean check
./gradlew clean check
```

Оба независимых запуска: 124 тестовых вызова, 0 отказов, ошибок и пропусков. Распределение: 5 архитектурных, 65 application, 15 domain, 16 infrastructure, 14 integration и 9 ui. FXML, CSS, миграции V001–V002 и оба CSV присутствуют в собранном JAR.

### Фактическое окно

```shell
./gradlew captureEvidence
```

Сценарий загрузил FXML/CSS, проверил отсутствие перекрытия формы и таблицы, ошибки имени и даты, исправление без перезапуска, дубликат, обе стороны границы 60/61 символ, устойчивый ID после сортировки и клавиатурный путь до сохранения по `Enter`. Снимки `ui-initial.png`, `ui-corrected.png` и `ui-keyboard-saved.png` просмотрены: текст и таблица не обрезаны, форма доступна в прокручиваемой панели.

### Автономное воспроизведение

```shell
./gradlew --offline clean check
./gradlew --offline run --args="--smoke"
```

Автономный `check` повторил 124 успешных запуска. Smoke-сценарий загрузил FXML и CSS из classpath, связал 3 поля и открыл локальную SQLite с одной начальной строкой в `.lesson-data` практики 18.
