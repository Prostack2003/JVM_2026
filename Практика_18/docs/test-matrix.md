# Матрица сценариев и уровней практики 18

| Сценарий | Уровень | Ожидаемый результат | Доказательство |
|---|---|---|---|
| новый временный файл SQLite | infrastructure | чистое независимое состояние | `SqliteNutritionPlanRepositoryTest` + `@TempDir` |
| сохранение, закрытие и повторное открытие SQLite | infrastructure | запись и все поля сохранены | `recordSurvivesClosingAndReopeningDatabase` |
| рабочий путь FXML | ui resource | ресурс найден, объявлены контроллер и `#addPlan` | `packagedFxmlDeclaresControllerAndPrimaryHandler` |
| заведомо неверный путь FXML | ui resource, отрицательный | точный путь присутствует в диагностике | `missingClasspathResourceIsDiagnosable` |
| название, дата и статус, затем кнопка | ui journey | одна строка в таблице, сообщение и та же запись в репозитории | `userCanAddPlanThroughRealFxmlControls` |
| пробельное название | ui journey, отрицательный | видимая полевая ошибка, таблица и репозиторий пусты | `blankNameShowsFieldErrorAndDoesNotSave` |
| клавиатурный маршрут | ручной UI | `Tab`/`Shift+Tab` идут по форме, `Enter` сохраняет | ручной прогон и `captureEvidence` |
| изменение размера окна | ручной UI | форма не перекрывает таблицу | ручной осмотр |
| полный регрессионный набор | все пакеты | все тесты зелёные | `./gradlew clean check` |
| повторный полный запуск | регрессия | тот же итог без общих данных | второй `clean check` |
| автономная регрессия | воспроизводимость | сборка использует подготовленный кэш | `./gradlew --offline clean check` |

Статус ручных пунктов фиксируется отдельно: зелёный автоматический отчёт не переносит вывод на все ОС и варианты масштабирования.
