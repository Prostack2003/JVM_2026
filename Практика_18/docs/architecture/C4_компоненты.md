# C4: компоненты и границы проверок

```mermaid
flowchart LR
    domainTest["domain tests"] --> model["NutritionPlan"]
    applicationTest["application tests"] --> service["NutritionPlanService"]
    sqliteTest["infrastructure tests"] --> sqlite["временная SQLite"]
    integrationTest["integration tests"] --> boundary["loopback HTTP + temp cache"]
    resourceTest["FxmlResourceTest"] --> resources["FXML/CSS в classpath и JAR"]
    uiTest["JavaFxUserJourneyTest"] --> controls["реальные FXML-контролы"]
    controls --> controller["MainController"]
    controller --> service
    service --> memory["MemoryNutritionPlanRepository"]
```

UI-проверка доказывает связность пользовательского пути и наблюдаемый результат. SQL проверяется рядом с реальным адаптером, а правила модели — на самой узкой границе. Такое разделение локализует отказ и не требует общей пользовательской базы или Интернета.
