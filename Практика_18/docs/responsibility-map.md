# Карта ответственности проверок

| Проверка | Доказывает | Не доказывает |
|---|---|---|
| `NutritionPlanTest` | инварианты, границы и неизменяемую смену состояния | SQL, FXML и пользовательский маршрут |
| application tests | координацию сценариев через порты | поведение настоящей SQLite и внешний вид |
| `SqliteNutritionPlanRepositoryTest` | миграции, SQL, ограничения, транзакции и повторное открытие временного файла | связь кнопки с обработчиком |
| integration tests | HTTP/JSON и файловый кэш с локальными границами | внешний Интернет и UI |
| `FxmlResourceTest` | classpath-путь, контроллер, обработчик и обязательные признаки разметки | выполнение действия пользователем |
| `JavaFxUserJourneyTest` | путь от реальных FXML-контролов через сервис к наблюдаемой строке | качество шрифтов и доступность на каждой ОС |
| `captureEvidence` | клавиатурный маршрут, компоновку и фактические состояния текущего окна | чистую установку и все варианты масштабирования |
| `check` | совместную регрессию всех автоматических уровней | ручное исследование интерфейса |
