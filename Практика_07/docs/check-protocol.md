Проверка выполнена на OpenJDK 25.0.4, Javac 25.0.4 и Gradle 9.1.0. Полный вывод сохранён в `docs/evidence/environment.txt`.

## Доказательства

- `docs/evidence/environment.txt` — версии Java, Javac, Gradle и параметры проекта;
- `docs/evidence/tests.txt` — чистая сборка, 17 JUnit-проверок и проверка ресурсов JAR;
- `docs/evidence/ui-run.txt` — фактическая FXML/JavaFX-проверка;
- `docs/evidence/smoke-run.txt` — запуск рабочего приложения после сборки;
- `docs/evidence/offline-run.txt` — повтор полного набора без сети;
