# Протокол проверки практики 11

Дата проверки: 1 октября 2026 года.

## Среда

JDK/Javac 25.0.4, Gradle Wrapper 9.1.0, Linux amd64. Фактический вывод сохранён в `evidence/environment.txt`.

## Приёмочные сценарии

| Команда/сценарий | Ожидание | Фактический результат |
|---|---|---|
| `./gradlew clean check testDatabase runLessonDemo` | чистая компиляция, JUnit, ресурсы в JAR и JDBC-demo | успешно: 35 основных тестов и 8 тестов задачи `testDatabase`; 0 ошибок |
| вставка и чтение | все поля и апостроф совпадают | подтверждено тестом и `runLessonDemo` |
| закрытие и повторное открытие | запись остаётся в том же файле | подтверждено двумя экземплярами репозитория и двумя отдельными smoke-запусками |
| нормализованный дубликат | ограничение `UNIQUE`, понятный предметный отказ, строки не меняются | получен точный `DuplicatePlanException` |
| некорректные данные в БД | ограничение статуса или диагностируемая ошибка чтения даты | оба сценария подтверждены интеграционными тестами |
| упаковка ресурсов | FXML, CSS и V001 присутствуют в JAR | все три ресурса найдены |
| `./gradlew captureEvidence` | прежний UI работает поверх SQLite | успешно: форма, ошибки, клавиатура, сортировка и устойчивый ID проверены |
| `./gradlew run --args="--smoke"` | реальное окно загружается и закрывается, путь БД диагностируется | успешно; `.lesson-data/nutrition-plans.db`, 1 сохранённая строка |
| повтор с `--offline` | сборка, SQLite-demo и UI работают без сети | обе автономные команды успешны |

Отдельно просмотрено отсутствие абсолютного пути в исходниках. Пользовательские значения связываются методами `setString`/`setLong`; `Statement` применяется только к фиксированным `PRAGMA` и SQL начальной схемы. Сервис и контроллер не зависят от `SqliteNutritionPlanRepository`.
