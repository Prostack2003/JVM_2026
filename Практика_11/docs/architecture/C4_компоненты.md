# C4: компоненты и зависимости исходного кода

```mermaid
flowchart LR
    user["Пользователь"] --> ui["DesktopApp + FXML + MainController"]
    ui --> contract["NutritionPlanOperations"]
    proxy["Dynamic proxy"] -. implements .-> contract
    proxy --> service["NutritionPlanService"]
    service --> port["NutritionPlanRepository<br/>domain port"]
    adapter["SqliteNutritionPlanRepository"] -. implements .-> port
    adapter --> jdbc["JDBC + PreparedStatement"]
    jdbc --> db[("SQLite file")]
    schema["InitialSchema + V001 resource"] --> db
    root["ApplicationContext"] --> proxy
    root --> service
    root --> adapter
```

Контроллер и сервис не знают конкретный адаптер. Все зависимости направлены к прикладным и предметным контрактам; SQLite сосредоточена в инфраструктурном слое.
