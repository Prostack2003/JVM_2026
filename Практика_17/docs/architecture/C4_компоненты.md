# C4: границы проверок

```mermaid
flowchart LR
    rules["NutritionPlanTest<br/>правила и границы"] --> domain["NutritionPlan<br/>предметная модель"]
    serviceTests["application tests"] --> application["прикладные сервисы"]
    dbTests["SQLite integration tests"] --> sqlite["временная SQLite"]
    httpTests["HTTP/cache integration tests"] --> loopback["loopback + temp cache"]
    resourceTest["verifyPackagedResources"] --> jar["собранный JAR"]
    smoke["smoke"] --> ui["FXML + controller + SQLite"]
```

Целевой тест практики находится у самой узкой границы, способной доказать инварианты `NutritionPlan`. В нём отсутствуют JavaFX, база, HTTP и файловый кэш. Настоящие технологии остаются в отдельных интеграционных наборах, а `clean check` запускает портфель целиком.
