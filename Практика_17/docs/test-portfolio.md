# Портфель проверок практики 17

| Риск | Самая узкая подходящая граница | Проверка практики |
|---|---|---|
| недопустимый план создан | предметная модель | `NutritionPlanTest` |
| граница длины понята неверно | предметная модель | ровно 60 и 61 символ |
| смена статуса меняет исходник или теряет поля | предметная модель | `withStatusCreatesReplacementAndKeepsOriginalRecord` |
| тест пропускает пустое имя | качество самого теста | временная мутация `isBlank()` |
| нарушен SQL-контракт | реальная временная SQLite | унаследованный `SqliteNutritionPlanRepositoryTest` |
| нарушены HTTP/JSON/кэш | loopback-сервер и временный файл | унаследованные integration tests |
| FXML или CSS отсутствует в JAR | собранный архив | `verifyPackagedResources` |

Практика 17 добавляет модульные доказательства правил модели. Полный `check` сохраняет регрессию остальных уровней, но они не подменяют целевой профиль `testDomainRules`.
