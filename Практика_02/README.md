# Практика 02. Данные, условия, циклы и методы

Самостоятельный проект на Java 25 в предметной области дневника питания КБЖУ. Программа определяет просроченные плановые даты пересмотра целей питания, выводит каждую такую цель и рассчитывает их количество и процент.

## Предметный контракт

Пересмотр цели просрочен, если его плановая дата **строго раньше** контрольной даты. Пересмотр, назначенный на контрольную дату, ещё находится в сроке. Дубликаты — отдельные записи и учитываются по отдельности.

Контрольная дата передаётся в методы параметром. Системная текущая дата не используется, поэтому все примеры воспроизводимы.

## Требования

- полный JDK 25;
- Linux, macOS или Windows с терминалом;
- доступ к Интернету только при первой загрузке Gradle 9.1.0.

Проверка среды:

```shell
java -version
javac -version
```

## Сборка и запуск

Из папки `Практика_02` выполните:

```shell
./gradlew clean run
```

Для Windows:

```text
gradlew.bat clean run
```

Ожидаемый предметный результат: из трёх дат `08.09.2026`, `09.09.2026` и `10.09.2026` при контроле `09.09.2026` просрочена одна запись — от `08.09.2026`.

## Автоматическая проверка сценариев

```shell
./gradlew clean check
```

Задача `check` запускает десять проверок без внешних тестовых библиотек: нормальную выборку, пустой массив, равенство с границей, дубликаты, массивы из одного элемента, три расчёта процента и некорректную отсутствующую дату.

Проверка без сети после первой успешной загрузки Gradle:

```shell
./gradlew --offline clean check run
```

## Контролируемый отказ

Эксперимент с условием цикла `index <= plannedDates.length` выполнялся только во временной копии. Он закономерно завершился `ArrayIndexOutOfBoundsException` с кодом `1`, после чего в рабочем исходнике сохранено правильное условие `index < plannedDates.length`. Порядок и результат зафиксированы в `docs/off-by-one-experiment.md`.
