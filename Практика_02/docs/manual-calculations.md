# Ручные расчёты

Контрольная дата во всех примерах: `09.09.2026`.

## Расчёт 1. Даты вокруг границы

| Плановая дата | Сравнение | Просрочена |
|---|---|---|
| `08.09.2026` | раньше контрольной | да |
| `09.09.2026` | равна контрольной | нет |
| `10.09.2026` | позже контрольной | нет |

Количество: `1`. Процент: `(double) 1 / 3 × 100 = 33,333333...%`.

## Расчёт 2. Пустой массив

Количество записей: `0`. Метод возвращает `0.0%` до операции деления, поэтому деления на ноль нет.

## Расчёт 3. Две просроченные даты из четырёх

Даты: `07.09.2026`, `08.09.2026`, `09.09.2026`, `10.09.2026`.

Первые две даты раньше контрольной, две остальные не просрочены. Количество: `2`. Процент: `(double) 2 / 4 × 100 = 50.0%`.

Машинная проверка этих трёх расчётов выполняется командой `./gradlew runChecks` и зафиксирована в `evidence/clean-check.txt`.
