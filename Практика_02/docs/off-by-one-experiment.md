# Эксперимент с границей массива

## Цель

Показать, почему индексный цикл должен использовать условие `index < plannedDates.length`.

## Порядок

1. Создана временная копия метода подсчёта, не входящая в собираемый проект.
2. В копии правильное условие `index < plannedDates.length` заменено на ошибочное `index <= plannedDates.length`.
3. Метод запущен для массива из трёх дат.
4. Ошибочная копия завершилась с ненулевым кодом из-за обращения к индексу `3` при допустимых индексах `0`, `1`, `2`.
5. Рабочий исходник проверен повторно: в нём сохранено условие `<`, сборка и все сценарии проходят.

## Ожидаемый и фактический результат

| Проверка | Ожидается | Фактически |
|---|---|---|
| Ошибочный цикл с `<=` | `ArrayIndexOutOfBoundsException` и ненулевой код | `ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3`, код `1` |
| Рабочий цикл с `<` | Корректный подсчёт одной записи | 1 запись; все 10 сценариев пройдены |

Необработанный вывод эксперимента сохраняется в `evidence/off-by-one.txt`.
