# Проверка модели без интерфейса

Модель проверяется отдельно от JavaFX, базы данных и HTTP.

## Чек-лист

- [x] Название и назначение типа понятны без интерфейса.
- [x] Все обязательные поля перечислены в компактном конструкторе.
- [x] Для каждого поля указан недопустимый пример.
- [x] Невозможный строковый статус исключён использованием `enum`.
- [x] Смена состояния возвращает новую запись.
- [x] Исходная запись остаётся доступной и неизменной.
- [x] Нормальный, граничные и отрицательные сценарии проверяются JUnit.
- [x] В модели нет методов сохранения, SQL или зависимостей от интерфейса.

Команда независимой проверки:

```shell
./gradlew clean test
```
