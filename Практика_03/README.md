# Практика 03. Предметная модель и допустимые состояния

Самостоятельный проект на Java 25 в предметной области дневника питания КБЖУ. Практика вводит неизменяемую запись `NutritionPlan`, проверяет её инварианты и показывает смену состояния путём создания нового объекта.

## Предметный результат

План питания содержит идентификатор, название, дату начала и одно из четырёх состояний:

- `DRAFT` — черновик;
- `ACTIVE` — действующий план;
- `COMPLETED` — завершённый план;
- `NEEDS_REVIEW` — план требует пересмотра.

Компактный конструктор не допускает отрицательный идентификатор, пустое название, отсутствующую дату или состояние. Нулевой идентификатор разрешён для новой записи до сохранения. По принятому правилу внешние пробелы названия удаляются.

Метод `withStatus` возвращает новую запись и не изменяет исходную.

## Требования

- полный JDK 25;
- Linux, macOS или Windows с терминалом;
- доступ к Интернету при первой загрузке Gradle и JUnit.

Проверка среды:

```shell
java -version
javac -version
```

## Сборка, тесты и запуск

Из папки `Практика_03` выполните:

```shell
./gradlew clean test run
```

Для Windows:

```text
gradlew.bat clean test run
```

После первой успешной загрузки зависимостей проверка выполняется без сети:

```shell
./gradlew --offline clean test run
```

Ожидаемый маршрут: создать черновик плана, получить новую запись со статусом `ACTIVE` и подтвердить, что исходная запись осталась в статусе `DRAFT`.

## Структура

- `src/main/java/ru/npi/kbju/domain/NutritionPlan.java` — предметная запись, enum и инварианты;
- `src/main/java/ru/npi/kbju/Practice03App.java` — консольный маршрут;
- `src/test/java/ru/npi/kbju/domain/NutritionPlanTest.java` — восемь JUnit-проверок;
- `docs/domain-model.md` — диаграмма, состояния и правила полей;
- `docs/decision.md` — объяснение решения и границ ответственности;
- `docs/peer-review.md` — проверка модели без интерфейса;
- `docs/check-protocol.md` — ожидаемые и фактические результаты;
- `docs/evidence/` — выводы проверочных запусков.

На этом этапе проект не использует JavaFX, базу данных, HTTP или существующий TypeScript-backend.
