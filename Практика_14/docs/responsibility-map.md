# Карта ответственности

| Участник | Делает | Не делает |
|---|---|---|
| `DeterministicCounterRace` | координирует два read-modify-write и атомарных increment | не выдаёт случайную гонку за доказательство |
| `ParallelNutritionDiagnostics` | фиксирует снимок, создаёт задачи, ждёт `Future`, отменяет при отказе | не знает JavaFX, JDBC и репозиторий |
| `Operation` | анализирует один неизменяемый план | не публикует общий итог |
| `DiagnosticBatch` | хранит полные итоги и факт закрытия | не хранит рабочие `Future` |
| `WaitingTaskCancellation` | проверяет `cancel(true)`, interrupt и отсутствие остаточных задач | не завершает поток насильно |
| `ConcurrencyDemo` | собирает приёмочные сценарии и завершается с ошибкой при несовпадении | не является продуктовым UI |
| `SqliteNutritionPlanRepository` | читает и сохраняет планы в своей границе | не передаёт `Connection` в параллельные задачи |
