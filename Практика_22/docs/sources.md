# Изученные источники

## Материалы курса

- `00_Маршрут_24_практик.docx` — наблюдаемый результат практики 22 и граница со следующей практикой.
- `П22_Методические_указания.docx` — app-image, запуск без IDE, ресурсы, данные вне установки и требования к протоколу.
- `П22_Презентация.pptx` с заметками — порядок демонстрации, проверка чистого запуска и критерии приёмки.
- `Лекция_11_Поставка_приложения_зависимости_образ_приложения_и_чистая_установка.docx` — `installDist`, `jdeps`, `jpackage`, runtime image, данные и обновление.
- `Учебно_методическое_пособие_JVM_настольные_приложения.docx`, модуль 11 — различие JAR, runtime image и app-image, зависимость сборки от целевой ОС.

## Связанные проекты

- Собственная `Практика_21` — проверенный накопительный проект с JAR, FXML/CSS и `ServiceLoader`.
- Демонстрационный проект преподавателя для практики 22 — только критерии, рубрика, схема `installDist → jpackage` и идея отдельного launcher-процесса.

Имя `KbjuDiary`, аргумент каталога данных, автоматизированный маршрут JavaFX, набор runtime-модулей, Gradle-задачи и документация написаны для дневника КБЖУ. Код пакета `servicejournal` и предметная модель оборудования не копировались.
