# Контракт расширения отчёта КБЖУ

## Назначение

Интерфейс `NutritionReportPlugin` позволяет добавлять представление одной уже проверенной суточной сводки без изменения кода обнаружения. Практика содержит два формата: `plain` и `compact`.

## Условия поставщика

- уникальный непустой `id`;
- публичный конструктор без аргументов;
- непустой детерминированный результат для допустимой сводки;
- отсутствие файлового, сетевого и пользовательского ввода внутри `format`;
- полное имя класса в `META-INF/services/ru.npi.kbju.report.NutritionReportPlugin` для classpath;
- запись `provides` в `module-info.java` для именованного модуля.

`DailyNutritionSummary` отклоняет отрицательные или нечисловые значения до вызова поставщика. Форматировщик не исправляет предметные данные.

## Граница безопасности

Поставщик выполняется с полномочиями процесса приложения. `ServiceLoader` не проверяет происхождение JAR, не ограничивает файловый или сетевой доступ и не создаёт песочницу. Поэтому разрешены только реализации, собранные и проверенные вместе с приложением.

## Альтернатива

Если проекту нужен только один стабильный формат, обычная реализация без SPI проще и безопаснее. SPI оставлен как небольшая учебная граница расширения: он оправдан наличием двух действительно разных форматов, но не превращается в магазин внешних плагинов.
