# Протокол проверки практики 22

Дата проверки: 4 октября 2026 года.

## Среда

- OpenJDK, `javac` и `jpackage` 25.0.4.1;
- Gradle Wrapper 9.1.0;
- Linux amd64;
- проверка выполнена из подготовленного кэша Gradle без сети;
- app-image запускался в доступном графическом сеансе.

|---|---|

| `analyzeDependencies` | обнаружены `java.base`, `java.net.http`, `java.sql`, `javafx.controls`, `javafx.fxml`, `jdk.httpserver` и Jackson |

| первый `verifyPackagedLaunch` | в копии app-image вне проекта запись добавлена через JavaFX-форму; строк стало 2 |

Первый пробный образ без `java.scripting` завершился `NoClassDefFoundError: javax/script/Bindings`. Ошибка не была скрыта структурной проверкой: её обнаружил фактический запуск скопированного образа. После добавления модуля оба запуска прошли успешно. Это подтверждает, почему одного `jdeps` и просмотра файлов недостаточно для FXML-приложения.

Полные краткие выводы команд сохранены в [`docs/evidence`](evidence/). Временные каталоги приёмки удаляются после проверки; исходники и каталоги сборки в них отсутствуют.

## Граница результата

Фактически проверена поставка Linux/amd64. Для Windows и macOS необходимо выполнить отдельную сборку и тот же сценарий на целевой ОС; текущий протокол не объявляет их проверенными.

## Итог

Критерии практики 22 выполнены: app-image запускается без IDE и внешнего JDK, загружает FXML/CSS, сохраняет запись после перезапуска и держит изменяемые данные вне каталога установки.
