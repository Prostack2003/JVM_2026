# Портфель проверок практики 22

| Риск | Самая дешёвая достаточная граница | Проверка |
|---|---|---|
| launcher не создан или неисполняем | файловая структура | `verifyAppImage` |
| основной JAR или runtime потерян | файловая структура | `verifyAppImage` |
| FXML/CSS отсутствуют в поставке | содержимое JAR образа | точная проверка ZIP entries |
| в конфигурацию попал путь исходников | launcher `.cfg` | поиск абсолютного пути проекта |
| в установку попали пользовательские данные | всё дерево образа | запрет `.db` и `.log` |
| сокращённый runtime пропустил динамический модуль | реальный процесс | `verifyPackagedLaunch` |
| проверка случайно использует системную Java | диагностический вывод | сравнение `java.home` с runtime копии |
| приложение зависит от текущего проекта | копия образа во временном каталоге | запуск с рабочим каталогом вне исходников |
| FXML/CSS есть, но окно не загружается | JavaFX-процесс | применение CSS и выполнение формы |
| запись не сохраняется между процессами | два последовательных запуска | `add`, затем `verify` |
| база создаётся внутри установки | файловая система | внешний `--data-dir` и проверка пути |
| архив повреждён или подменён | байтовый поток | SHA-256 |
| прежние функции сломаны | полный накопительный набор | `clean check` и smoke-запуск |

На пробной сборке реальный процесс обнаружил отсутствующий `java.scripting`, который не был очевиден из статического списка `jdeps`. После исправления портфель защищает от повторения этого дефекта.
