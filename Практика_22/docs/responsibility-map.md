# Карта ответственности

| Компонент | Делает | Не делает |
|---|---|---|
| `installDist` | собирает JAR и runtime-зависимости в предсказуемую структуру | не создаёт нативный launcher или runtime image |
| `jdeps` | сообщает статически наблюдаемые зависимости модулей | не доказывает динамическую загрузку FXML и service providers |
| `jpackage` | создаёт app-image с launcher и встроенной Java для текущей ОС | не собирает универсальный образ для других ОС |
| `verifyAppImage` | проверяет структуру, ресурсы и отсутствие изменяемых данных | не утверждает, что окно действительно запускается |
| `verifyPackagedLaunch` | копирует образ, запускает два процесса и проверяет пользовательский маршрут | не использует IDE или каталог исходников |
| `Launcher` | применяет явный `--data-dir` и запускает JavaFX | не выбирает внутренний путь установки для данных |
| `DesktopApp` | загружает FXML/CSS и выполняет приёмочный маршрут через контроллер | не создаёт образ поставки |
| `AppConfig` | отделяет SQLite, журнал и резервные копии от приложения | не удаляет пользовательские данные при обновлении |
| `packageAppImageArchive` | создаёт воспроизводимый архив проверенного образа | не заменяет платформенное тестирование |
| пользователь | распаковывает/заменяет app-image и сохраняет каталог данных | не обязан устанавливать JDK |
