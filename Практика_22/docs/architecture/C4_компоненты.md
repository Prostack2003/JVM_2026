# C4: компоненты поставки

```mermaid
flowchart LR
    gradle["Gradle Wrapper 9.1"] --> dist["installDist"]
    jar["JAR приложения"] --> dist
    deps["runtimeClasspath"] --> dist
    jar --> jdeps["jdeps"]
    dist --> jpackage["jpackage --type app-image"]
    jdeps --> modules["явный список модулей"]
    modules --> jpackage
    jpackage --> image["KbjuDiary app-image"]
    image --> structural["verifyAppImage"]
    image --> launch["verifyPackagedLaunch"]
    launch --> archive["tar.gz + SHA-256"]
```

Статический анализ используется как подсказка. Итоговый артефакт принимается только после фактического запуска скопированного образа и повторного открытия сохранённых данных.
