# Инструкция пользователя

## Назначение

Приложение хранит локальные планы питания. Пользователь может добавить план, указать дату начала и состояние, сделать выбранный план активным, удалить запись и запустить аудит списка.

## Первый запуск готового комплекта

1. Распакуйте архив app-image в каталог, доступный для чтения и выполнения.
2. На Linux запустите `KbjuDiary/bin/KbjuDiary`. На Windows используйте `KbjuDiary.exe`. На macOS откройте приложение из app bundle.
3. Не переносите файлы базы внутрь каталога установки. Приложение создаёт пользовательский каталог данных автоматически.

Выпуск фактически проверен только на Linux/amd64. Для другой платформы требуется собственная сборка и отдельный протокол.

## Добавление плана

1. Введите непустое название длиной не более 60 символов.
2. Укажите дату в формате `ГГГГ-ММ-ДД`.
3. Выберите состояние.
4. Нажмите «Добавить».

После успешного сохранения запись появляется в таблице. Если поле заполнено неверно, приложение показывает причину рядом с полем и не удаляет остальные введённые значения.

## Состояние и аудит

Выберите строку и нажмите «Сделать активным», чтобы изменить состояние по устойчивому идентификатору. Кнопка «Начать аудит» проверяет неизменяемый снимок списка в фоне. Отмена или учебный отказ не публикуют неполный результат.

## Повторный запуск

Закройте приложение обычным способом и запустите тот же комплект снова. Ранее сохранённые планы должны появиться в таблице. Если приложение не открывает данные, не удаляйте базу: сохраните сообщение и код события, затем проверьте доступ к пользовательскому каталогу.

## Резервная копия

В текущем выпуске резервное копирование и восстановление представлены проверяемым инженерным сценарием, а не кнопкой интерфейса. Не заменяйте рабочую базу вручную. Разработчик выполняет восстановление только в новый файл по `docs/recovery-protocol.md`.

## Удаление приложения

Удаление каталога app-image не удаляет пользовательские данные, потому что база и журналы находятся вне установки. Перед удалением данных отдельно сохраните резервную копию.
