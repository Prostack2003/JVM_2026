# Карта ответственности

| Компонент | Делает | Не делает |
|---|---|---|
| `NutritionPlan` (Java) | хранит проверенное неизменяемое состояние | не форматирует подпись поставки |
| `NutritionPlanCaption` (Kotlin) | проверяет nullable-вход и строит стабильную строку | не обращается к UI, БД или сервисам |
| `@JvmStatic` | публикует предсказуемый статический метод Java | не отменяет необходимость теста сигнатуры |
| `InteropDemo` (Java) | показывает обычный вызов и контролируемый null-отказ | не создаёт предметные данные в хранилище |
| `KotlinInteropTest` | проверяет значения, null, границу и JVM-сигнатуру | не проверяет состав дистрибутива |
| `verifyKotlinDistribution` | проверяет JAR, stdlib и запускает Java из `installDist` | не использует исходные каталоги как runtime |
| Kotlin Gradle Plugin | компилирует Kotlin и формирует runtime classpath | не мигрирует Java-код автоматически |
| `--patch-module` | включает Kotlin output в тот же JPMS-модуль при `javac` | не создаёт второй прикладной модуль |
