# Паспорт учебного выпуска 24.0.0

## Идентификация

| Поле | Фактическое значение |
|---|---|
| продукт | Дневник питания КБЖУ |
| область выпуска | локальное управление планами питания |
| версия | `24.0.0` |
| дата приёмки | 4 октября 2026 года |
| JDK | OpenJDK `25.0.4.1` |
| Gradle | Wrapper `9.1.0` |
| Kotlin | `2.4.10` |
| подтверждённая платформа | Linux/amd64 |
| хранилище | SQLite, миграции V001–V002 |

## Критерий и решение

Пять сценариев текущего мини-ТЗ имеют статус `ПРОЙДЕНО` и воспроизводимые доказательства. Выпуск принят для учебной демонстрации на Linux/amd64 с ограничениями из `known-limitations.md`.

Фактическая передача второму человеку не выполнялась, поэтому этот пункт имеет отдельный статус `НЕ ПРОВЕРЕНО`. Автоматическая проверка чистого запуска вне исходного каталога пройдена и не подменяет человеческую проверку инструкции.

## Состав поставки

- app-image `KbjuDiary` со встроенной Java;
- исходники Java и Kotlin;
- Gradle Wrapper и файлы сборки;
- пользовательская и разработческая инструкции;
- матрица прослеживаемости и протокол проверки;
- манифест выпуска в JAR;
- архив app-image и финальный release bundle с файлами SHA-256.

## Данные и восстановление

Рабочая SQLite и журналы создаются вне каталога установки. Резервная копия проходит `PRAGMA integrity_check`; восстановление допускается только в новый тестовый файл. Проверка не удаляет и не перезаписывает пользовательские файлы.

## Подтверждённые свойства

- чистая сборка и полный набор тестов;
- обычный и отрицательный UI-сценарии;
- сохранение записи после перезапуска app-image;
- безопасное поведение при недоступном локальном HTTP-сервисе;
- восстановление проверенной SQLite-копии;
- Java–Kotlin-совместимость и наличие Kotlin runtime;
- состав JAR, app-image и финального архива;
- smoke-запуск FXML, CSS, конфигурации и SQLite.

## Контрольные суммы

Фактические имена архивов и SHA-256 фиксируются в `docs/evidence/release-distribution.txt` после чистой сборки. Файл `.sha256` создаётся рядом с каждым архивом.
