# ADR 024. Критерий учебного выпуска

## Контекст

Накопленный проект содержит автоматические тесты, app-image и инженерные демонстрации. Само наличие артефактов не связывает пользовательское требование с фактическим результатом и не показывает границы продукта.

## Решение

Версия 24.0.0 принимается по пяти строкам матрицы. Каждая строка содержит наблюдаемое требование, реализацию, автоматическую проверку, команду и сохранённое доказательство. Статус `ПРОЙДЕНО` назначается только после фактического прогона.

Финальный release bundle содержит app-image, исходники, документацию и SHA-256. Непроверенные платформы и человеческая передача перечисляются отдельно и не получают положительный статус.

## Последствия

- изменение сценария указывает, какие тесты и документы обновить;
- защита начинается с пользовательского результата;
- широкий первоначальный замысел не смешивается с фактическим выпуском;
- сборка выпуска занимает больше времени из-за app-image и двух процессов JavaFX;
- платформенная проверка остаётся отдельной для каждой ОС и архитектуры.
