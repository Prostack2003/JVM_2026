# Проверка передачи комплекта

## Автоматическая чистая среда

`verifyPackagedLaunch` копирует app-image во временный каталог вне проекта, назначает отдельный каталог данных и запускает launcher дважды. Первый запуск добавляет запись через реальные элементы FXML, второй находит её в SQLite. Дополнительно проверяются встроенная Java, FXML, CSS и отсутствие данных внутри установки.

Статус: `ПРОЙДЕНО` на Linux/amd64.

## Проверка инструкции человеком

Второй человек в текущей среде недоступен. Фактический запуск другим студентом без устных подсказок не выполнялся.

Статус: `НЕ ПРОВЕРЕНО`.

Следующее действие: перед защитой передать release bundle второму студенту, дать только `README.md` и `docs/user-guide.md`, записать каждый вопрос и повторить сценарий после уточнения инструкции.

## Контрольный лист второго участника

- распаковать комплект;
- найти launcher без подсказки;
- добавить план;
- получить понятный отказ на пустом названии;
- перезапустить приложение и найти запись;
- найти ограничения и контрольную сумму;
- сообщить непонятные или отсутствующие шаги.

`НЕ ПРОВЕРЕНО` означает отсутствие результата проверки. `НЕ ПРОЙДЕНО` использовалось бы только после выполненного сценария, в котором участник не смог достичь ожидаемого результата.
