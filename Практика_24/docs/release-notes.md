# Заметки о выпуске 24.0.0

## Добавлено

- матрица прослеживаемости пяти сценариев;
- паспорт выпуска и разделённые инструкции для пользователя и разработчика;
- семиминутный сценарий защиты;
- манифест выпуска внутри основного JAR;
- автоматическая проверка документов и финального release bundle;
- две отдельные команды для отказа локального сервиса и восстановления SQLite;
- SHA-256 для app-image-архива и полного комплекта.

## Исправлено

- начальный текст аудита теперь содержит полное слово `результат`;
- сообщение отмены аудита больше не содержит обрезанного слова;
- регрессионный UI-тест проверяет исправленный текст.

## Совместимость

Формат SQLite остаётся V002. Миграция данных не требуется. Java–Kotlin-контракт и публичная сигнатура форматировщика не изменены.
