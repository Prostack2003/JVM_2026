# Изменение состава поставки

## Сравнение с практикой 23

| Элемент | Практика 23 | Практика 24 |
|---|---|---|
| основной JAR | `jvm-practice-23-23.0.0.jar` | `jvm-practice-24-24.0.0.jar` |
| Kotlin и stdlib | включены | сохранены и повторно проверяются |
| манифест выпуска | отсутствует | `ru/npi/kbju/release/release-manifest.txt` |
| документация | по техническому этапу | пользовательская, разработческая и приёмочная |
| архив | app-image | app-image и полный release bundle |
| критерий | Java–Kotlin interop | пять трассируемых сценариев и ограничения |

Практика 24 собирается самостоятельно и не читает `build` предыдущей папки. `verifyReleaseBundle` использует только собственный app-image, исходники и документы.
