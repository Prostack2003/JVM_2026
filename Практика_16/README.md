# Практика 16. Кэш, повторный запрос и автономный режим

Самостоятельный Gradle-проект дневника питания КБЖУ. Справочник продуктов загружается по HTTP, а после полной проверки атомарно сохраняется в JSON-кэш. При временном сетевом отказе приложение честно показывает источник, время и возраст последней подтверждённой копии.

## Требования

- JDK 25 (проверено на 25.0.4);
- Gradle Wrapper 9.1;
- графическая среда только для наследуемого JavaFX-окна;
- Интернет нужен только для первой загрузки сборочных зависимостей.

## Сборка и приёмка

Из каталога `Практика_16`:

```shell
./gradlew clean check testOfflineCatalog runLessonDemo
```

Windows:

```text
gradlew.bat clean check testOfflineCatalog runLessonDemo
```

`runLessonDemo` запускает `ru.npi.kbju.lesson.OfflineCatalogDemo` и воспроизводит:

1. свежий ответ и создание кэша;
2. две ограниченные попытки при HTTP 500 и переход к кэшу;
3. повреждённый ответ без перезаписи хорошей копии;
4. первый автономный запуск со статусом «Нет сохранённых данных»;
5. явный отказ повреждённого кэша;
6. границу TTL и ручной повтор после восстановления сервера.

Повтор без внешней сети:

```shell
./gradlew --offline clean check testOfflineCatalog runLessonDemo
```

## Политика отказов

- GET выполняется не более двух раз с паузой 100 мс.
- Retry допустим для таймаута, транспортного отказа, HTTP 429 и 5xx.
- HTTP 401/403, повреждённый JSON и нарушение контракта не маскируются старыми данными.
- Кэш допустим до 24 часов включительно. После границы возвращается `EXPIRED_CACHE`.
- Время кэша в будущем даёт `CLOCK_ROLLBACK`.
- Второе параллельное обновление отклоняется как `UPDATE_IN_PROGRESS`; после завершения доступен ручной повтор.

Полный контракт: [кэш и автономная работа](docs/offline-catalog-contract.md).

## Операции без сети

Непросроченный кэш разрешает читать справочник и использовать его в локальных расчётах КБЖУ. Добавление записей питания и веса остаётся локальной операцией SQLite и не выдаётся за синхронизированную. Обновление внешнего справочника без сети запрещено.

## Наследуемое окно

```shell
./gradlew run
./gradlew run --args="--smoke"
```

Данные окна хранятся в `.lesson-data/nutrition-plans.db`; каталог исключён из Git.
