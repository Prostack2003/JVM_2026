## Чистая сборка и тесты

Команда:

```shell
./gradlew clean check testOfflineCatalog runLessonDemo
```

Фактический результат:

- основной набор: 112 JUnit-запусков, 0 отказов;
- профиль `testOfflineCatalog`: 24 запуска, 0 отказов;
- FXML, CSS, миграции V001–V002 и CSV-ресурсы найдены в JAR;
- демонстрация подтвердила сеть, fallback, отсутствие и повреждение кэша, TTL и восстановление;
- `BUILD SUCCESSFUL`.

Профиль состоит из 3 тестов прикладного каталога, 7 тестов устойчивого сервиса, 3 тестов файлового кэша, 4 тестов JSON-маппера, 6 тестов HTTP-адаптера и 1 сквозного сценария.

## Проверенные отказы

| Сценарий | Фактический результат |
|---|---|
| HTTP 500/503 | не более двух запросов, затем свежий подтверждённый кэш |
| повреждённый сетевой JSON | ошибка `MALFORMED_JSON`; хорошая копия не изменена |
| HTTP 401 | одна попытка; старые данные не маскируют отказ доступа |
| первый offline-запуск | `NO_SAVED_DATA` и действие повторного запроса |
| повреждённый файл | `CORRUPT_CACHE`, записи не показаны |
| возраст ровно 24 часа | копия допустима |
| возраст больше 24 часов | `EXPIRED_CACHE` |
| время получения в будущем | `CLOCK_ROLLBACK` |
| конкурентное обновление | второй запрос получает `UPDATE_IN_PROGRESS`; ручной повтор доступен после завершения |

## Повтор без внешней сети

Команда:

```shell
./gradlew --offline clean check testOfflineCatalog runLessonDemo
./gradlew --offline run --args="--smoke"
```

Gradle не обращался к внешним репозиториям; тесты, локальный HTTP-сервер, демонстрация и smoke-сценарий завершились успешно. Локальный сервер из тестов не является внешней сетью.

## Регрессия интерфейса

Два последовательных запуска `./gradlew run --args="--smoke"` загрузили FXML и CSS из classpath, открыли одну и ту же SQLite-базу и увидели одну сохранённую строку. Это подтверждает, что расширение сетевого слоя не нарушило прежние сценарии практик.
