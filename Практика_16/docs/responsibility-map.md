# Карта ответственности

| Участник | Делает | Не делает |
|---|---|---|
| `ResilientProductCatalogService` | ограничивает retry, выбирает fallback, проверяет TTL и запрещает параллельный refresh | не знает HTTP, JSON и файлы |
| `RetryPolicy` | фиксирует конечное число попыток и паузу | не решает, какие отказы временные |
| `ProductCatalogCache` | задаёт порт целого подтверждённого снимка | не фиксирует формат хранения |
| `FileProductCatalogCache` | читает и перепроверяет JSON, пишет временную копию и заменяет файл | не оценивает TTL и не выбирает fallback |
| `HttpProductDirectory` | сохраняет точный HTTP-код и класс сетевого отказа | не повторяет запрос и не читает кэш |
| `CatalogSnapshot` | передаёт данные, источник, время, возраст и причину fallback | не скрывает кэш под видом свежего ответа |
| `OfflineCatalogDemo` | воспроизводит все сдаваемые состояния на loopback-сервере и временных файлах | не является продуктовым UI |
