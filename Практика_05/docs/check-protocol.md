# Протокол проверки практики 05

## Среда

Проверка выполнена на OpenJDK 25.0.4, Javac 25.0.4 и Gradle 9.1.0. Полный вывод сохранён в `docs/evidence/environment.txt`.

## Автоматические проверки

| Проверка | Ожидаемый результат | Фактический результат |
|---|---|---|
| Чистая сборка и JUnit | Все проверки модели и сервиса проходят | Пройдено: 13 из 13, ошибок и пропусков нет |
| Первый запуск JavaFX | Окно содержит одну исходную строку | Пройдено: `строк=1` |
| Название «Поддержание массы» | Добавлена ровно одна строка, поле очищено, показано подтверждение | Пройдено: `строк=2`, подтверждение показано |
| Пустое поле | Число строк не меняется, сообщение объясняет исправление | Пройдено: осталось `строк=2`, показана просьба ввести непустое название |
| Изменение размеров | Таблица и форма остаются доступны, одно нажатие добавляет одну строку | Пройдено при 860×500: элементы видны, после одного нажатия стало `строк=3` |
| Повторный запуск | Снова одна исходная строка | Пройдено отдельным smoke-запуском: `Начальное число строк: 1` |
| Запуск без сети | Сборка, тесты и JavaFX-сценарии используют подготовленный кэш | Пройдено: обе команды завершились `BUILD SUCCESSFUL` |

## Доказательства

- `docs/evidence/environment.txt` — версии Java, Javac и Gradle;
- `docs/evidence/tests.txt` — результат JUnit;
- `docs/evidence/ui-run.txt` — фактический вывод JavaFX-сценариев;
- `docs/evidence/offline-run.txt` — итог повторной проверки без сети;
- `docs/evidence/ui-success.png` — состояние после корректного ввода;
- `docs/evidence/ui-error.png` — состояние после пустого ввода;
- `docs/evidence/ui-resized.png` — окно после уменьшения размера.

Снимки созданы самим JavaFX-приложением после фактического выполнения действий. Они не заменяют исходники и текстовый протокол, а дополняют их наблюдаемым состоянием интерфейса.
