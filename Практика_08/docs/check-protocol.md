## Приёмочные сценарии

| Сценарий | Фактический результат |
|---|---|
| Только пробелы | Отказ, строка не добавлена, дата и статус сохранены, фокус на названии |
| Неверная дата `2026-13-40` | Пойман только `DateTimeParseException`; формат и пример показаны возле даты; строка не добавлена |
| Исправление на `2026-11-01` | Запись сохранена без перезапуска, таблица увеличилась ровно на одну строку |
| Отсутствующая дата | Понятное сообщение с действием; таблица неизменна |
| 61 символ в названии | Одинаковый вход отклонён формой и моделью; таблица неизменна |
| Ровно 60 символов в названии | Одинаковая граница принята формой и моделью без усечения |
| Повтор имени без учёта регистра | Пойман `DuplicatePlanException`; поля сохранены; ID не израсходован |
| Отсутствующее состояние | Сообщение возле списка, фокус на списке, таблица неизменна |
| Только клавиатура | Начальный фокус без мыши; `Tab`, `Shift+Tab`, `Enter` пройдены; запись сохранена |
| Повтор после ошибки | Кнопка не заблокирована; повторная команда доступна |

## Статическая граница исключений

В `src/main/java` найдены только три конкретных обработчика:

- `DateTimeParseException`;
- `DuplicatePlanException`;
- `PlanValidationException`.

`catch (Exception)` и `catch (Throwable)` в рабочем коде отсутствуют.

## Визуальная проверка

Все семь снимков открыты и просмотрены: элементы не обрезаны, ошибка расположена непосредственно под полем, текст читаем, таблица не перекрывает форму. Цветовая рамка всегда дополнена текстом. Файлы находятся в `docs/evidence/`.
