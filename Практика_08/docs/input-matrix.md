# Матрица проверки ввода

| Вход | Ожидаемое состояние формы | Ожидаемое состояние данных |
|---|---|---|
| Название — пустая строка | Текст возле названия просит ввести значение; фокус на названии | Таблица без изменений |
| Название — только пробелы | Сообщение явно отличает пробелы от допустимого названия; введённые пробелы, дата и статус сохранены | Таблица без изменений |
| Название длиной 60 символов | Ввод допустим | Добавляется одна запись |
| Название длиной 61 символ | Сообщение предлагает сократить название до 60 символов; фокус на названии | Таблица без изменений; модель отклоняет тот же вход |
| Дата отсутствует | Возле даты указан формат `ГГГГ-ММ-ДД` и пример | Таблица без изменений |
| Дата `2026-13-40` | Контроллер ловит `DateTimeParseException`; значение остаётся; фокус на дате | Таблица без изменений |
| Дата `2026-11-01` после ошибки | Ошибка снимается, форма сообщает об успехе | Ровно одна новая запись |
| Состояние отсутствует | Возле списка есть действие «Выберите состояние»; фокус на списке | Таблица без изменений |
| Повтор ` поддержание МАССЫ ` | Сообщение просит изменить название; все поля сохранены | `DuplicatePlanException`; таблица без изменений, ID не расходуется |
| Корректные название, дата и состояние | Сообщение об успехе; название очищено, фокус готов к следующей записи | Добавляется одна нормализованная запись |

Проверяемые одинаковым входом ограничения модели и формы:

1. название не может быть пустым или состоять из пробелов;
2. нормализованное название не может быть длиннее 60 символов.
