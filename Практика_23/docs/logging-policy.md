# Политика безопасного журнала

## Разрешённый контекст

- стабильное имя события;
- случайный `eventId`, который пользователь сообщает при обращении;
- операция из фиксированного перечисления;
- исход и код причины из фиксированного перечисления;
- признак источника настроек без абсолютных домашних путей.

## Запрещённые данные

- пароли, токены и заголовки `Authorization`;
- названия и содержимое личных планов питания;
- измерения массы и история рациона;
- тела HTTP-запросов и ответов целиком;
- произвольный `toString()` модели, конфигурации или исключения;
- stack trace, если он не прошёл отдельную очистку.

`ApplicationLog.recordFailure` принимает `Throwable`, чтобы вызывающий код не потерял техническую причину в своей ветке обработки, но намеренно не переносит сообщение или stack trace в файл. Журнал получает только типизированные `Operation` и `FailureReason`.

## Хранение

Java `FileHandler` ограничивает один файл размером 256 Кбайт и использует три поколения. Обработчик закрывается при завершении приложения, чтобы снять lock-файл. Перед передачей фрагмента другому человеку пользователь выбирает только строки нужного `eventId`; база данных в диагностический набор не включается.
