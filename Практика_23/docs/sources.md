# Изученные источники

## Материалы курса

- `00_Маршрут_24_практик.docx` — наблюдаемый результат практики 23 и граница с итоговой приёмкой.
- `П23_Методические_указания.docx` — изолированный Kotlin-компонент, Java-вызов, null-контракт и проверка `installDist`.
- `П23_Презентация.pptx` с заметками — порядок демонстрации, матрица обычного и отрицательного сценариев, критерии сдачи.
- `Лекция_12_Целостный_настольный_продукт_требования_доказательства_качества_и_инжене.docx` — оба направления interop, `@JvmStatic`, platform type и воспроизводимые доказательства.
- `Учебно_методическое_пособие_JVM_настольные_приложения.docx`, модуль 12 — минимальная совместимость без полной миграции и необходимость Kotlin runtime в поставке.
