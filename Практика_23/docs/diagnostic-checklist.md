# Памятка диагностики

1. **Воспроизведение.** Записать версию приложения, выполненное действие, ожидаемый результат, фактическое сообщение и код события. Не повторять постоянный отказ много раз.
2. **Проверка среды.** Запустить `./gradlew runLessonDemo`, сверить источник настроек и разрешённые пути. При отказе назвать ключ конфигурации, не копируя секретное значение и не открывая рабочую базу.
3. **Минимальные доказательства.** Найти строки журнала по `eventId` и передать только их вместе с шагами воспроизведения. Не отправлять весь каталог данных, SQLite, токены, содержимое планов и персональные измерения.
