# ADR 013: фоновый аудит как Task-адаптер над независимым ядром

**Статус:** принято 2 октября 2026 года.

## Контекст

Длинный цикл в обработчике кнопки блокирует JavaFX Application Thread. Прямая зависимость аудитора от JavaFX мешает быстрой проверке без окна.

## Решение

1. `NutritionPlanAuditor` остаётся в `application` и не импортирует JavaFX.
2. `NutritionPlanAuditTask` находится в `ui`: передаёт `isCancelled`, вызывает `updateProgress` и `updateMessage`.
3. Вход копируется до запуска. Сводка публикуется только в `onSucceeded`.
4. Отмена проверяется до и после каждой порции. Каждый повтор создаёт новый `Task`.
5. Для приёмки `FAILED` в UI есть явный учебный режим, который не затрагивает SQLite.

## Альтернативы и последствия

Длинный цикл в FX Thread и `Platform.runLater` для каждого шага отклонены. `Service` отложен до этапа, где повторяемая операция станет постоянным сервисом экрана. Окно остаётся отзывчивым, а ценой решения становятся отдельный адаптер и явное восстановление UI для трёх исходов.
