# Изменение состава поставки

## Сравнение с практикой 22

| Элемент | Практика 22 | Практика 23 |
|---|---|---|
| основной JAR | `jvm-practice-22-22.0.0.jar` | `jvm-practice-23-23.0.0.jar` |
| Kotlin-класс | отсутствует | `NutritionPlanCaption.class` |
| Kotlin runtime | отсутствует | `kotlin-stdlib-2.4.10.jar` |
| UI и SQLite | Java | Java, без изменений |
| app-image | Java runtime и Java-зависимости | дополнительно Kotlin stdlib и Kotlin-класс |

Сравнение не создаёт зависимость от папки `Практика_22`: `Практика_23` собирается самостоятельно. Таблица объясняет наблюдаемое приращение, а автоматическая проверка исследует только собственный `build/install/jvm-practice-23/lib`.

## Автоматическая проверка

`verifyKotlinDistribution` требует:

1. каталог `installDist/lib`;
2. основной JAR с Kotlin-классом;
3. минимум один `kotlin-stdlib*.jar`;
4. успешный запуск Java `InteropDemo` только из JAR дистрибутива;
5. точное совпадение двух строк результата.

Наличие исходника `.kt` без runtime и фактического запуска не считается доказательством поставки.
