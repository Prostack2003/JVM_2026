# Системные требования поставки

## Проверенная платформа

- Linux amd64;
- графический сеанс X11 или Wayland;
- glibc;
- GTK 3 и связанные библиотеки GLib/GIO;
- Pango и Cairo;
- Fontconfig и FreeType;
- библиотеки X11 либо Wayland;
- OpenGL/GLX, поддерживаемые JavaFX.

JDK и Gradle конечному пользователю не требуются: Java находится внутри app-image. Для сборки нужны JDK 25 с `jpackage`/`jdeps` и Gradle Wrapper.

## Дисковое пространство и доступ

- app-image после сборки занимает приблизительно 117 МБ;
- архив поставки — приблизительно 55 МБ;
- пользователь должен иметь право записи в `~/.kbju-diary` либо каталог из `--data-dir`;
- каталог app-image может быть доступен только на чтение во время обычной работы.

## Платформенная граница

App-image содержит нативный launcher и JavaFX-библиотеки конкретной ОС и архитектуры. Linux-архив нельзя считать поставкой для Windows или macOS. Для каждой целевой комбинации ОС/архитектуры требуется отдельная сборка на этой ОС и повтор полного протокола чистого запуска.
