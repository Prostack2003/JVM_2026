# Практика 01. Выбор проекта и первый запуск Java

Самостоятельный учебный проект по предметной области дневника питания КБЖУ. На этом этапе программа только подтверждает выбранную тему, роль пользователя и проблему. В проекте ещё нет JavaFX, базы данных, HTTP и регистрации.

## Требования

- полный JDK 25;
- доступ к Интернету при первом запуске Gradle Wrapper;
- Linux, macOS или Windows с терминалом.

Проверьте, что `java` и `javac` относятся к одной версии JDK:

```shell
java -version
javac -version
```

## Сборка и штатный запуск

Из корня проекта выполните:

```shell
./gradlew clean run
```

В Windows используйте:

```text
gradlew.bat clean run
```

Ожидаемый вывод программы:

```text
Проект: «Дневник питания КБЖУ».
Пользователь: человек, который контролирует рацион и массу тела.
Проблема: разрозненные данные мешают достоверно учитывать КБЖУ, вес и историю изменений.
```

Точка входа находится в `src/main/java/ru/npi/kbju/HelloWorld.java`. Gradle запускает класс `ru.npi.kbju.HelloWorld`.

## Контролируемый отказ

Сначала скомпилируйте классы:

```shell
./gradlew classes
```

Затем намеренно укажите несуществующий класс:

```shell
java -cp build/classes/java/main ru.npi.kbju.MissingClass
```

Команда должна завершиться с ненулевым кодом и сообщить, что класс не найден. Этот отказ относится к запуску JVM: исходник уже скомпилирован, но JVM не может найти указанную точку входа. Команда не изменяет исходники и данные.

Для восстановления повторите правильный запуск:

```shell
./gradlew run
```
