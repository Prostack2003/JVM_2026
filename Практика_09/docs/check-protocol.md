# Протокол проверки практики 09

Дата проверки: 1 октября 2026 года.

## Среда

Ожидается JDK 25.0.4 и Gradle Wrapper 9.1. Фактический вывод сохранён в `evidence/environment.txt`.

## Выполненные сценарии

| Команда/сценарий | Ожидание | Фактический результат |
|---|---|---|
| `./gradlew clean check` | компиляция, все JUnit-тесты и проверка ресурсов проходят | успешно: 20 тестов, 0 ошибок; оба ресурса найдены в JAR |
| `./gradlew testService` | сервисные тесты проходят без окна | успешно: 4 теста сервиса, окно не создавалось |
| `./gradlew captureEvidence` | JavaFX-сценарий сохраняет снимки и подтверждает ID после сортировки | успешно: ID 1 остался выбран и получил состояние `ACTIVE` |
| `./gradlew run --args="--smoke"` | FXML/CSS загружаются, одна начальная строка, окно закрывается | успешно: 3 поля связаны, 1 строка, штатное завершение |
| повтор с `--offline` | сборка и smoke-запуск не обращаются к сети | обе команды успешны в режиме `--offline` |

Дополнительно проверяются независимость двух репозиториев, отсутствие частичного изменения при дубликате и запрещённые импорты между слоями.
