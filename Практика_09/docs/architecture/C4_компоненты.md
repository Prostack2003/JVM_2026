# C4: компоненты и зависимости исходного кода

```mermaid
flowchart LR
    user["Пользователь"] --> desktop["DesktopApp + FXML<br/>UI lifecycle"]
    desktop --> view["MainController<br/>UI coordination"]
    desktop --> root["ApplicationContext<br/>composition root"]
    view --> service["NutritionPlanService<br/>application"]
    view --> model["NutritionPlan + предметные ошибки<br/>domain"]
    service --> model
    service --> port["NutritionPlanRepository<br/>domain port"]
    adapter["MemoryNutritionPlanRepository<br/>infrastructure"] -. implements .-> port
    adapter --> model
    root --> service
    root --> adapter
    root --> model
    root --> port
```

Сплошная стрелка означает импорт и вызов. Пунктир — реализацию интерфейса. `MainController` не импортирует адаптер, `NutritionPlanService` не импортирует JavaFX или `infrastructure`, а домен зависит только от `java.base`.
