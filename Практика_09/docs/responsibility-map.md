# Карта ответственности

| Участник | Делает | Не делает |
|---|---|---|
| `NutritionPlan` | хранит неизменяемое состояние и защищает инварианты | не знает JavaFX, таблицу и способ хранения |
| `NutritionPlanRepository` | задаёт операции, нужные прикладному сценарию | не описывает SQL, файлы или элементы окна |
| `NutritionPlanService` | создаёт, изменяет и удаляет планы через порт | не создаёт репозиторий и не управляет `TableView` |
| `MemoryNutritionPlanRepository` | назначает ID, обеспечивает уникальность и хранит независимую коллекцию | не показывает сообщения пользователю |
| `MainController` | переводит значения формы в аргументы сервиса и обновляет представление | не владеет бизнес-коллекцией и не знает конкретный адаптер |
| `ApplicationContext` | выбирает адаптер и связывает зависимости | не содержит предметных правил |

## Направление исходных зависимостей

```text
ui/MainController ──> application ──> domain (модель + порт)
        │───────────────────────────> domain (отображаемая модель и ошибки)
infrastructure ─────────────────────> domain (модель + порт)
ApplicationContext ──> application + infrastructure + domain
```

Точка сборки намеренно расположена снаружи слоёв. Это позволяет заменить память следующим адаптером, не переписывая контроллер и сервис.
