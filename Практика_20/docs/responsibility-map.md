# Карта ответственности

| Компонент | Делает | Не делает |
|---|---|---|
| `SqliteBackupService` | создаёт снимок SQLite, проверяет структуру и публикует новый файл | не знает JavaFX и не заменяет рабочую базу |
| `BackupException` | хранит стабильную причину отказа и техническую цепочку | не анализирует текст сообщения в вызывающем коде |
| `DatabaseInspection` | фиксирует путь, `integrity_check`, версию и число планов | не запускает миграции и не меняет базу |
| `SqliteNutritionPlanRepository` | читает восстановленные предметные записи | не выбирает резервный файл и не управляет политикой хранения |
| `BackupRecoveryDemo` | создаёт временные входы, сравнивает записи и проверяет отказ | не открывает пользовательскую `.lesson-data` |
| `AppConfig` | предоставляет настроенные пути рабочей базы и каталога копий | не создаёт и не восстанавливает снимки |
