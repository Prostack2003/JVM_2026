# ADR-019: конфигурация и безопасный журнал

**Статус:** принято.

## Контекст

Путь SQLite ранее задавался только системным свойством, а отдельного журнала приложения не было. Запуск из другого рабочего каталога и технический отказ было трудно объяснить без риска запросить у пользователя всю базу или содержимое личной записи.

## Решение

- хранить изменяемые пути во внешнем UTF-8 `application.properties`;
- разрешать относительные значения только от явного корня `kbju.data.dir`;
- проверять конфигурацию и готовить каталоги до открытия SQLite;
- различать отсутствующее значение с default и явно пустое значение с отказом;
- журналировать только типизированные события с `eventId`, операцией и кодом причины;
- показывать пользователю действие для продолжения, не технический stack trace.

## Последствия

Одинаковая конфигурация даёт одинаковые пути независимо от каталога терминала. Отказы можно связать по `eventId`, не записывая токены и содержимое планов. Внешний файл становится частью поставки и требует документированных значений по умолчанию. Настройка каталога копий подготавливает практику 20, но резервное копирование здесь не реализуется.
