# C4: резервное копирование и восстановление

```mermaid
flowchart LR
    config["AppConfig"] --> source["рабочая SQLite"]
    config --> backupDir["каталог копий"]
    service["SqliteBackupService"] --> source
    service --> stagedBackup["временный снимок"]
    stagedBackup --> verify["integrity + schema + count"]
    verify --> backup["проверенная копия"]
    backup --> stagedRestore["временное восстановление"]
    stagedRestore --> verifyRestore["повторная проверка"]
    verifyRestore --> newDatabase["новый тестовый файл"]
    newDatabase --> repository["SqliteNutritionPlanRepository"]
    repository --> compare["сравнение NutritionPlan"]
```

`SqliteBackupService` работает на инфраструктурной границе и не знает JavaFX. `BackupRecoveryDemo` координирует только временные учебные пути. Рабочая база приложения не является целью восстановления.
