# Протокол проверки практики 20

Дата проверки: 3 октября 2026 года.

## Среда

- OpenJDK и `javac` 25.0.4;
- Gradle Wrapper 9.1.0;
- Linux 7.0.0-31-generic amd64;
- JavaFX 25, графический сеанс `DISPLAY=:0`.

## Ожидаемые результаты

| Проверка | Ожидаемый результат |
|---|---|
| хороший снимок | открывается отдельно, `integrity=ok`, схема 2 и ожидаемые записи |
| изменение после снимка | остаётся только в рабочей базе |
| восстановление | выполняется в новый тестовый путь, записи совпадают со снимком |
| повреждённый файл | отказ до создания цели; рабочая база и хороший снимок неизменны |
| существующая цель | отказ без перезаписи |
| два полных прогона | одинаковый зелёный результат |
| автономный прогон | сеть не требуется |

демонстрации создавались только в `/tmp`; пользовательская `.lesson-data` не была
источником или целью восстановления.

## Итог

Все критерии практики 20 выполнены. Копия создаётся согласованным механизмом
SQLite, проходит отдельное чтение и контроль структуры. Восстановление публикуется
только в новый тестовый файл, а отрицательный сценарий сохраняет рабочую базу и
исправный снимок.
