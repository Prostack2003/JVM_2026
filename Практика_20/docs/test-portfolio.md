# Портфель проверок практики 20

| Риск | Самая дешёвая достаточная граница | Проверка |
|---|---|---|
| снимок существует, но не читается | настоящий SQLite во временном каталоге | отдельное открытие, `integrity_check`, схема и число строк |
| копирование теряет журнальное состояние | `VACUUM INTO` при открытом репозитории | снимок живой базы и сравнение записей |
| старая копия неожиданно включает поздние данные | две последовательные версии рабочей базы | проверка отсутствия позднего плана |
| повреждённый файл заменяет рабочие данные | отдельные damaged/source/backup/target | причина отказа, отсутствие цели и сравнение SHA-256 |
| пользователь выбирает занятую цель | файловая граница | точный `TARGET_EXISTS`, байты цели сохранены |
| единственная копия перезаписывается | повтор того же пути | прежний SHA-256 не меняется |
| новая программа открывает чужую схему | журнал миграций | точный `UNSUPPORTED_SCHEMA` до публикации цели |
| SQL-путь ломается на апострофе | реальный `VACUUM INTO` | каталог `О'Нил` |
| прежние функции нарушены | полный накопительный набор | `clean check` |

Все тестовые базы создаются в `@TempDir`. Личные данные и `.lesson-data` пользователя не используются.
