# Карта ответственности

| Компонент | Делает | Не делает |
|---|---|---|
| `AppConfig` | читает Properties, применяет defaults, разрешает и проверяет пути | не открывает SQLite и не записывает журнал |
| `AppConfigurationException` | называет проблемный ключ и сохраняет техническую причину | не публикует исходное значение пользователю |
| `ApplicationLog` | пишет разрешённые поля, создаёт `eventId`, управляет `FileHandler` | не хранит секреты, записи дневника и произвольные сообщения исключений |
| `DesktopApp` | показывает дальнейшее действие пользователю и связывает код события с журналом | не формирует SQL и не раскрывает stack trace |
| `ApplicationContext` | открывает SQLite по уже разрешённому пути | не выбирает рабочий каталог терминала |
| `ConfigurationDemo` | показывает пути и безопасный фрагмент журнала | не читает содержимое базы |
