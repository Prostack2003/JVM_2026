# Протокол проверки практики 19

Дата проверки: 3 октября 2026 года.

## Среда

- OpenJDK и `javac` 25.0.4;
- Gradle Wrapper 9.1.0;
- Linux 7.0.0-31-generic amd64;
- JavaFX 25, графический сеанс `DISPLAY=:0`.

## Ожидаемые результаты

| Проверка | Ожидаемый результат |
|---|---|
| штатный файл | пути базы, журнала и копий доступны |
| отдельная допустимая конфигурация | поведение меняется только под учебным root |
| файл или ключ отсутствует | применяется документированный default |
| пустой или неверный путь | ранний отказ с конкретным ключом |
| диагностический отказ с секретом | событие полезно, секрет и личная запись отсутствуют |
| два полных прогона | одинаковый зелёный результат |
| автономный прогон | сеть не требуется |

## Фактические результаты

| Проверка | Фактический результат |
|---|---|
| `java -version`, `javac -version` | OpenJDK и компилятор 25.0.4 |
| `./gradlew clean testDiagnostics` | 10 тестов, 0 отказов |
| `./gradlew clean check`, два раза | оба запуска успешны; по 134 тестовых вызова, 0 отказов |
| `./gradlew runLessonDemo` | показаны разрешённые пути, сообщение пользователю и безопасное событие журнала |
| отдельный root и `application-custom.properties` | три относительных пути разрешены только под учебным root |
| чувствительная причина отказа | токен и содержимое личного плана отсутствуют в журнале |
| `./gradlew --offline clean check` | успешная автономная сборка без сети |
| `./gradlew --offline run --args="--smoke"` | FXML/CSS, SQLite, конфигурация и журнал успешно открыты |
| `./gradlew --offline captureEvidence` | реальный JavaFX-маршрут выполнен; два контрольных снимка просмотрены |

Фактические логи сохранены в [`docs/evidence`](evidence/). Временные данные,
файлы SQLite и рабочие журналы находятся в `.lesson-data` и в Git не добавляются.

## Итог

Все критерии практики 19 выполнены. Настройки и пользовательские данные имеют
разный жизненный цикл, изменяемые пути вынесены во внешний файл, неверные значения
останавливают запуск до предметной работы, а диагностика использует ограниченный
набор полей без секретов и содержимого записей.
