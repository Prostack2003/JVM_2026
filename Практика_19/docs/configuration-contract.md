# Контракт конфигурации

## Выбор файлов и корня

| Вход | Значение по умолчанию | Назначение |
|---|---|---|
| системное свойство `kbju.data.dir` | `${user.home}/.kbju-diary` | явный корень изменяемых данных |
| системное свойство `kbju.config` | `config/application.properties` | внешний файл свойств |
| Gradle `-PkbjuDataDir` | `<проект>/.lesson-data` | безопасный учебный корень для `run` и `runLessonDemo` |
| Gradle `-PkbjuConfig` | `config/application.properties` | учебный выбор другого файла |

Путь файла конфигурации без `kbju.config` считается от рабочего каталога процесса. Пути внутри файла имеют другое правило: относительные значения всегда разрешаются от нормализованного `kbju.data.dir`.

## Параметры приложения

| Ключ | Значение по умолчанию | Для чего меняется |
|---|---|---|
| `database.path` | `data/nutrition-plans.db` | расположение SQLite в конкретной среде |
| `log.directory` | `logs` | место журналов с отдельной политикой хранения |
| `backup.directory` | `backup` | цель будущих согласованных копий практики 20 |

Остальные константы предметной модели, ограничения имени, состояния планов, имена событий и формат даты не являются настройками среды и остаются в коде.

## Отказы

- отсутствующий файл: применяются все документированные значения по умолчанию;
- отсутствующий отдельный ключ: применяется значение по умолчанию только для этого ключа;
- пустое значение или синтаксически неверный путь: ранний отказ с именем ключа;
- файл вместо требуемого каталога или запрет записи: отказ подготовки с именем ключа;
- абсолютное значение: используется после нормализации без привязки к корню данных.

Конфигурация создаёт каталоги базы, журнала и резервных копий, но не создаёт саму SQLite до открытия репозитория.
