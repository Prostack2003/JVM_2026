# C4: конфигурация и диагностика

```mermaid
flowchart LR
    properties["config/application.properties"] --> config["AppConfig"]
    system["kbju.data.dir / kbju.config"] --> config
    config --> database["путь SQLite"]
    config --> logs["каталог журналов"]
    config --> backup["каталог будущих копий"]
    desktop["DesktopApp"] --> config
    desktop --> context["ApplicationContext"]
    context --> sqlite["SqliteNutritionPlanRepository"]
    desktop --> logger["ApplicationLog"]
    logger --> logFile["application-%g.log"]
    logger --> notice["eventId в сообщении пользователя"]
```

Файл настроек выбирается относительно процесса, но значения внутри него разрешаются от `dataRoot`. `DesktopApp` сообщает дальнейшее действие, а `ApplicationLog` получает только безопасный код причины.
