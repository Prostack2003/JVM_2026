# Контракт и правила наблюдения

| Public-метод `NutritionPlanOperations` | Аннотация | Учитывается proxy | Причина |
|---|---|---|---|
| `all` | нет | нет | техническое чтение для обновления представления |
| `addPlan` | «Создать план питания» | да | выбранная предметная команда |
| `addDraft` | нет | нет | вспомогательный сценарий, не выбранный для демонстрации |
| `remove` | нет | нет | не входит в две наблюдаемые операции этапа |
| `changeStatus` | «Изменить состояние плана питания» | да | выбранная предметная команда |

Аннотации находятся на методах интерфейса: именно эти объекты `Method` получает обработчик стандартного dynamic proxy. Метрика означает число попыток вызова отмеченной команды, поэтому отказавший предметный вызов также учитывается.

## Ограничения безопасности

- читаются только методы, возвращённые `Class.getMethods()`;
- закрытые поля и методы не открываются, `setAccessible` отсутствует;
- имя метода не принимается от пользователя и не используется для выполнения;
- аргументы, названия планов и другие пользовательские данные не записываются в метрики;
- proxy делегирует заранее внедрённому объекту, а не самому себе;
- исходная причина `InvocationTargetException` немедленно передаётся вызывающему коду.

Если удалить `RetentionPolicy.RUNTIME`, `getAnnotation` во время выполнения вернёт `null`, каталог станет пустым и отмеченные операции перестанут учитываться. Финальная версия сохраняет `RUNTIME`; это дополнительно проверяется тестом.
