# C4: компоненты и зависимости исходного кода

```mermaid
flowchart LR
    user["Пользователь"] --> ui["DesktopApp + FXML + MainController"]
    ui --> service["NutritionPlanOperations"]
    csv["UTF-8 CSV"] --> parser["NutritionPlanCsvParser"]
    parser --> importer["NutritionPlanImportService"]
    importer --> batchPort["NutritionPlanBatchRepository"]
    adapter["SqliteNutritionPlanRepository"] -. implements .-> batchPort
    adapter -. implements .-> crudPort["NutritionPlanRepository"]
    service --> crudPort
    adapter --> jdbc["JDBC + PreparedStatement<br/>commit / rollback"]
    jdbc --> db[("SQLite file")]
    migrator["SchemaMigrator<br/>V001 → V002"] --> db
    history[("schema_migration")] --- db
```

Все строки CSV проверяются до вызова порта. Граница транзакции находится в SQLite-адаптере, потому что именно он владеет одним JDBC-соединением. `SchemaMigrator` изолирован от CRUD и импорта.
