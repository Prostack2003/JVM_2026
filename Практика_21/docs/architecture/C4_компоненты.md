# C4: загрузка форматов отчёта

```mermaid
flowchart LR
    jar["jvm-practice-21 JAR"] --> demo["PluginDemo"]
    demo --> api["NutritionReportPlugin"]
    demo --> loader["ServiceLoader"]
    descriptor["META-INF/services"] --> loader
    loader --> plain["PlainNutritionReport"]
    loader --> compact["CompactNutritionReport"]
    plain --> api
    compact --> api
    summary["DailyNutritionSummary"] --> api
    fxml["main-view.fxml"] --> jar
    css["style.css"] --> jar
```

`PluginDemo` зависит от публичного SPI и стандартного `ServiceLoader`, а не от классов поставщиков. Descriptor и реализации входят в тот же доверенный JAR. Внешний каталог плагинов отсутствует: расширение формата не является границей безопасности.
