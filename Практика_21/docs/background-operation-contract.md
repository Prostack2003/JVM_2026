# Контракт фонового аудита

## Вход

`MainController` создаёт `List.copyOf(visiblePlans)` в JavaFX Application Thread. После старта этот снимок не меняется. Каждый план проходит шесть коротких проверок: ID, нормализация и длина названия, дата, состояние и уникальность ID.

## Граница потоков

| Место | Поток | Разрешено | Запрещено |
|---|---|---|---|
| `MainController.startAudit` | JavaFX Application Thread | снимок, привязки, состояние кнопок | длительный цикл |
| `NutritionPlanAuditTask.call` | виртуальный рабочий поток | вызов аудитора, `updateProgress`, `updateMessage` | изменение `Label`, `ProgressBar`, `TableView` |
| `NutritionPlanAuditor.audit` | рабочий поток | проверка снимка, точки отмены | JavaFX, SQL-запись |
| `setOnSucceeded/Cancelled/Failed` | JavaFX Application Thread | публикация итога или причины, восстановление экрана | повторная фоновая работа |

## Конечные состояния

| Исход | Что публикуется | Восстановление |
|---|---|---|
| `SUCCEEDED` | новый `AuditResult`, 100 % | разрешить новый запуск |
| `CANCELLED` | статус отмены; прежний итог не меняется | снять привязки, разрешить повтор |
| `FAILED` | понятная причина; прежний итог не меняется | снять привязки, разрешить повтор |

Отмена не откатывает данные: аудит только читает снимок. Его безопасная точка — граница между двумя короткими проверками.
