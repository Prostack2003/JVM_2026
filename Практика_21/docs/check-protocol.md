# Протокол проверки практики 21

Дата проверки: 3 октября 2026 года.

## Среда

- OpenJDK и `javac` 25.0.4;
- Gradle Wrapper 9.1.0;
- Linux amd64;
- все зависимости использованы из подготовленного кэша Gradle.

## Ожидаемые результаты

| Проверка | Ожидаемый результат |
|---|---|
| обычная сборка | основной JAR создан из чистого состояния |
| состав JAR | классы, FXML, CSS и service descriptor присутствуют |
| два поставщика | два разных отчёта без изменения клиентского цикла |

Критерии практики 21 выполнены. Обычная поставка содержит два формата и нужные ресурсы. Потеря service descriptor не маскируется: classpath-запуск завершается явным отказом. Произвольные внешние расширения не подключаются.
