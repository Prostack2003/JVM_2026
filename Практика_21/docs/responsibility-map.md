# Карта ответственности

| Компонент | Делает | Не делает |
|---|---|---|
| `DailyNutritionSummary` | хранит проверенные числа суточной сводки | не форматирует и не выполняет ввод-вывод |
| `NutritionReportPlugin` | задаёт минимальный контракт имени и форматирования | не выбирает поставщика и не даёт изоляцию |
| `PlainNutritionReport` | создаёт полный текстовый отчёт | не знает о загрузчике и UI |
| `CompactNutritionReport` | создаёт короткую строку КБЖУ | не меняет модель и файлы |
| `META-INF/services` | связывает интерфейс с поставщиками на classpath | не проверяет доверие к коду |
| `PluginDemo` | загружает поставщиков, проверяет непустой различимый результат | не создаёт реализации напрямую |
| Gradle-проверки | собирают JAR, сверяют состав и запускают отрицательную копию | не устанавливают внешние плагины |
