# Портфель проверок практики 21

| Риск | Самая дешёвая достаточная граница | Проверка |
|---|---|---|
| исходник есть, но класс не попал в поставку | содержимое ZIP/JAR | белый список классов поставщиков |
| FXML или CSS потерян при сборке | содержимое JAR | `verifyJarContents` |
| поставщик скомпилирован, но не обнаруживается | фактический запуск из JAR | `runLessonDemo` |
| descriptor содержит опечатку или лишнюю строку | чтение ресурса из JAR | точное сравнение двух имён |
| поставщики выдают одинаковый результат | тест контракта на одной сводке | множество двух форматов |
| некорректные числа доходят до расширения | конструктор DTO | три отрицательных входа |
| отсутствие descriptor выглядит как успех | отдельная копия JAR | ожидаемый ненулевой процесс |
| клиент зависит от конкретного поставщика | анализ исходника и SPI-тест | цикл работает только с интерфейсом |
| прежние сценарии сломаны | полный накопительный набор | `clean check` |

Отрицательная копия создаётся только в `build/libs` и не изменяет основной JAR или исходный descriptor.
