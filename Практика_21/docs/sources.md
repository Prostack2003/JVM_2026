# Изученные источники

## Материалы курса

- `00_Маршрут_24_практик.docx` — наблюдаемый результат практики 21 и граница с `jpackage` из практики 22.
- `П21_Методические_указания.docx` — JAR-инвентаризация, два поставщика, сценарий без descriptor и граница доверия.
- `П21_Презентация.pptx` с заметками — порядок демонстрации, матрица проверки и вопрос о безопасности `ServiceLoader`.
- `Лекция_11_Поставка_приложения_зависимости_образ_приложения_и_чистая_установка.docx` — classpath, идентичность класса, поставщики и роль `META-INF/services`.
- `Учебно_методическое_пособие_JVM_настольные_приложения.docx`, модуль 11 — различие JAR, runtime image и app-image; разделение поставки и изменяемых данных.

- Демонстрационный проект преподавателя для практики 21 — только критерии, рубрика и стандартный механизм `ServiceLoader`.
