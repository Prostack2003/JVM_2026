# Карта ответственности

| Участник | Делает | Не делает |
|---|---|---|
| `MainController` | берёт снимок, создаёт Task, связывает свойства, обрабатывает 3 исхода | не выполняет длинный цикл |
| `NutritionPlanAuditTask` | связывает ядро с JavaFX Worker API | не изменяет визуальные узлы |
| `NutritionPlanAuditor` | порционно проверяет снимок, проверяет отмену, выдаёт прогресс | не знает JavaFX, SQLite и FXML |
| `AuditResult` | хранит только полный итог | не хранит частичное состояние |
| `NutritionPlanOperations` | даёт контроллеру текущие планы | не зависит от Task |
| `SqliteNutritionPlanRepository` | хранит планы из прежнего этапа | не получает сигнал отмены, потому что аудит не пишет в БД |
