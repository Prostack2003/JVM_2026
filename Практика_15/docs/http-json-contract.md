# HTTP/JSON-контракт

## Запрос

| Свойство | Значение |
|---|---|
| Метод | `GET` |
| Путь | `/api/v1/products` |
| Адрес учебного сервера | `http://127.0.0.1:<свободный порт>/api/v1/products` |
| Заголовок | `Accept: application/json` |
| Таймаут соединения | 2 с |
| Таймаут запроса | 3 с |
| Предел тела | 65 536 байт |

Учебный `LocalProductDirectoryServer` привязан к loopback-адресу. По умолчанию он просит у ОС свободный порт, поэтому тесты не зависят от фиксированного номера.

## Успешный ответ

Сервер возвращает статус `2xx`, `Content-Type: application/json` и один объект:

```json
{
  "version": 1,
  "products": [
    {
      "code": "FOOD-001",
      "name": "Гречневая крупа",
      "energyKcal": 343,
      "proteinGrams": 13.3,
      "fatGrams": 3.4,
      "carbohydrateGrams": 71.5
    }
  ]
}
```

Полный пример: [`examples/products-valid.json`](examples/products-valid.json).

## Проверка контракта

Порядок обработки не меняется:

1. завершить HTTP-запрос с таймаутом;
2. принять только статус 2xx;
3. проверить JSON-тип и предел размера;
4. разобрать синтаксис в JSON-дерево;
5. проверить `version == 1`, массив `products` и все обязательные типы полей;
6. создать доменные `FoodProduct`, проверяя их инварианты;
7. отклонить дубликаты `code`;
8. однократно опубликовать `List.copyOf(products)`.

Неизвестные поля игнорируются для обратно совместимого расширения. Пропущенные, `null`-поля и неверные типы отклоняются. Предел каталога — 1000 записей.

## Причины отказа

| `DirectoryLoadException.Kind` | Условие | Состояние каталога |
|---|---|---|
| `HTTP_STATUS` | HTTP не 2xx | прежний снимок |
| `MALFORMED_JSON` | ошибка синтаксиса JSON | прежний снимок |
| `CONTRACT` | неверный тип, схема, дубликат или доменный инвариант | прежний снимок |
| `TIMEOUT` | истёк таймаут | прежний снимок |
| `TRANSPORT` | DNS/соединение/ввод-вывод | прежний снимок |
| `INTERRUPTED` | фоновый поток прерван | прежний снимок, interrupt восстановлен |

Ответ `HTTP 200` с HTML или с формально целым, но предметно недопустимым JSON не считается успехом.
