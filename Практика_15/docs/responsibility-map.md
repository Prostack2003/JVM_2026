# Карта ответственности

| Участник | Делает | Не делает |
|---|---|---|
| `FoodProduct` | хранит неизменяемые поля и защищает диапазоны КБЖУ | не знает JSON и HTTP |
| `ProductDirectory` | задаёт порт получения доменных продуктов | не фиксирует транспорт |
| `ProductCatalogRefreshService` | запускает получение на переданном executor и атомарно меняет снимок | не знает URI, HTTP-статус и Jackson |
| `HttpProductDirectory` | строит GET, задаёт таймауты, проверяет статус, тип и размер ответа | не публикует каталог |
| `FoodProductJsonMapper` | различает ошибку синтаксиса и контракта, проверяет весь набор | не выполняет сетевые запросы |
| `LocalProductDirectoryServer` | воспроизводит 200, 500, повреждённый/недопустимый JSON и задержку | не зависит от Интернета |
| `HttpJsonDemo` | собирает приёмочный маршрут, проверяет сохранность и освобождение порта | не является продуктовым UI |
