# C4: компоненты и зависимости исходного кода

```mermaid
flowchart LR
    caller["UI / консольный сценарий"] --> service["ProductCatalogRefreshService<br/>фоновое обновление"]
    executor["Executor<br/>не JavaFX Application Thread"] --> service
    service --> port["ProductDirectory<br/>прикладной порт"]
    adapter["HttpProductDirectory<br/>status + timeout + size"] -. implements .-> port
    adapter --> client["java.net.http.HttpClient"]
    client --> server["LocalProductDirectoryServer<br/>127.0.0.1, свободный порт"]
    adapter --> mapper["FoodProductJsonMapper<br/>Jackson tree + контракт"]
    mapper --> product["FoodProduct<br/>доменные инварианты"]
    product --> snapshot["List.copyOf<br/>подтверждённый снимок"]
    snapshot --> service
```

Направление зависимостей идёт внутрь: HTTP-адаптер знает прикладной порт и доменную модель, но пакеты `application.catalog` и `domain` не знают о `java.net.http`, Jackson и JavaFX.

Сетевой кандидат проходит все проверки до публикации. При HTTP-, JSON- или предметном отказе `AtomicReference` остаётся на прежнем неизменяемом списке.
