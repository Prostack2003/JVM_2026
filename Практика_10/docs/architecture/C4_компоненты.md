# C4: компоненты и зависимости исходного кода

```mermaid
flowchart LR
    user["Пользователь"] --> desktop["DesktopApp + FXML"]
    desktop --> view["MainController"]
    desktop --> root["ApplicationContext"]
    view --> contract["NutritionPlanOperations<br/>application interface"]
    proxy["Dynamic proxy<br/>observation"] -. implements .-> contract
    proxy --> metrics["OperationCallMetrics"]
    proxy --> service["NutritionPlanService"]
    service -. implements .-> contract
    service --> port["NutritionPlanRepository<br/>domain port"]
    adapter["MemoryNutritionPlanRepository"] -. implements .-> port
    service --> model["NutritionPlan + errors"]
    adapter --> model
    catalog["OperationCatalog"] --> contract
    root --> proxy
    root --> service
    root --> adapter
```

Контроллер вызывает интерфейс и не знает, что текущий объект является proxy. Reflection используется только компонентом диагностики. Предметная модель не зависит от JavaFX, reflection или инфраструктуры.
